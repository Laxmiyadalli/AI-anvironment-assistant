# 🌍 AI Environment Assistant

An AI-powered Environment Assistant built using Python and Streamlit that helps users understand environmental conditions, analyze environmental data, and receive AI-generated recommendations for sustainable living. The application leverages Generative AI to provide intelligent insights and promote eco-friendly decision-making.

---

## 🚀 Features

- 🌱 AI-powered environmental assistance
- 📊 Analyze environmental data
- 💬 Interactive chatbot for environmental queries
- ♻️ Provides sustainability recommendations
- 🌍 Promotes eco-friendly practices
- ⚡ Fast and user-friendly interface
- 🌙 Modern Streamlit web application

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/AI-environment-assistant.git
```

### 2. Navigate to the Project Folder

```bash
cd AI-environment-assistant
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure API Key

Create a `.env` file in the project directory.

```env
GEMINI_API_KEY=YOUR_API_KEY
```

### 5. Run the Application

```bash
streamlit run app.py
```
